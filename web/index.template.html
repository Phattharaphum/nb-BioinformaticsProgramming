03 / VERIFY

XML ↔ CSV

verify_output.py

อ่าน XML ซ้ำโดยไม่เรียก parse_drug เทียบทุก cell เก็บตัวอย่างและ hashes ก่อนแทนที่ผลลัพธ์ CSV และรายงาน

ทำไมต้อง spool?

header ต้องครอบคลุมยาที่มีรายการมากที่สุด ซึ่งทราบหลังอ่านครบ หากเก็บทุกยาใน RAM จะใช้หน่วยความจำมาก จึงพักค่าที่สกัดไว้ใน temporary JSONL แล้วอ่านกลับเพื่อเขียน CSV

ขนาดหน่วยความจำยังขึ้นกับยาที่ใหญ่ที่สุด parser buffer ชุด IDs สำหรับตรวจซ้ำ ตัวอย่าง 3 แถว และรายละเอียด complexes ในรายงาน

ผลเดิมจะถูกเขียนทับเมื่อไร?

หลัง parse, เขียน temporary CSV และตรวจเทียบผ่านแล้ว จึงเรียก os.replace เผยแพร่ CSV และ JSON ทีละไฟล์ หากสกัดหรือตรวจไม่ผ่านจะลบ temporary files ใน finally

การ replace แต่ละไฟล์เป็น atomic แต่ CSV และ JSON สองไฟล์ไม่ใช่ transaction เดียว หาก replace รายงานล้มเหลวหลัง replace CSV ต้องตรวจคู่ไฟล์ก่อนใช้งาน

ตัวอย่าง XML จำลองสำหรับเข้าใจโครงสร้าง

ตัดเฉพาะฟิลด์ที่ใช้ในบทเรียน ไม่ใช่ไฟล์ XML ต้นทางฉบับเต็ม

<drugbank xmlns="http://www.drugbank.ca">
  <drug>
    <drugbank-id primary="true">DB00001</drugbank-id>
    <name>Lepirudin</name>
    <targets>
      <target>
        <name>Prothrombin</name>
        <organism>Humans</organism>
        <actions><action>inhibitor</action></actions>
        <polypeptide id="P00734" source="Swiss-Prot">
          <gene-name>F2</gene-name>
        </polypeptide>
      </target>
    </targets>
  </drug>
</drugbank>

07 / RUN IT YOURSELF

รันโปรแกรมบนเครื่องของคุณ

Python 3.10 ขึ้นไป ใช้ standard library และ virtual environment

1. ดาวน์โหลดโค้ดและสร้าง venv

git clone git@github.com:Phattharaphum/nb-BioinformaticsProgramming.git
cd nb-BioinformaticsProgramming
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

requirements.txt ไม่มี package ภายนอก บน Windows ใช้ py -m venv .venv และ .venv\Scripts\Activate.ps1

2. วาง XML และสร้างผล

python group3.py
python group3.py --layout table \
  --output Drug_Target_table.csv
python verify_output.py --report verification.json
python -m unittest discover -v

วาง all_drug_2023.xml ที่ได้รับสำหรับโครงการใน root ก่อนรัน ไฟล์นี้ไม่อยู่ใน Git; เปลี่ยนตำแหน่งได้ด้วย --input /path/to/file.xml

CLI options ทั้งหมดและการแก้ปัญหา
Optionค่าเริ่มต้น / ตัวเลือกความหมาย
--inputall_drug_2023.xmlตำแหน่งต้นทาง
--input-formatxml / auto / textCLI เลือก XML เป็นหลัก ต้อง opt-in เพื่อกู้ TXT
--outputDrug_Target.csvชื่อผลลัพธ์
--layoutassignment / tableวงเล็บและแถวต่างความกว้าง / ตาราง rectangular
--reportoutput.validation.jsonตำแหน่งรายงาน ห้ามทับ input/output

ตัวตรวจใช้ --csv แทน --output และเลือก layout อัตโนมัติจาก header ฟังก์ชัน API รองรับ input_format="auto" ขณะที่ CLI เริ่มที่ xml

  • Input not found: ตรวจชื่อและตำแหน่ง XML; โปรแกรมไม่ fallback ไป TXT
  • ParseError: XML ผิดรูปแบบหรือขาดตอน ไม่ใช่ plain text
  • Invalid/duplicate ID: ตรวจ primary ID ของ drug ชั้นบนสุด
  • Mismatch at drug row…: ใช้แถว/คอลัมน์ในข้อความตรวจค่า CSV กับ XML
  • Output/report directory does not exist: สร้างโฟลเดอร์ก่อนรัน

สำเร็จ exit code 0; ผิดพลาด exit code 1 พร้อมข้อความใน stderr

08 / DOCUMENTED DECISIONS

!

Total-IonChannel ยังต้องยืนยันนิยาม

โจทย์ไม่ได้กำหนดเกณฑ์จำแนก ion channels ส่วน XML มี targets, enzymes, carriers และ transporters โปรแกรมนับ carriers ในคอลัมน์ที่สามตามสมมติฐานที่เปิดเผย แต่ carriers ไม่ใช่คำพ้องกับ ion channels

ตัวอย่าง DB00063 มี voltage-dependent N-type calcium channel อยู่ใน targets การนับ carriers จึงไม่ได้พิสูจน์จำนวน ion channels จริง และการค้นชื่อคำว่า channel อย่างเดียวไม่ใช่เกณฑ์ที่ครบถ้วน

specification_status = requires_ion_channel_definition
จุดที่พบสิ่งที่โปรแกรมเลือกทำ
ภาพใช้ Total-IonChannel; ข้อความใช้ Total-IonChanelใช้ตัวสะกด header ตามภาพ
Bivalirudin มีเลข 1 ทั้ง target และ enzymeเริ่ม protein_number ใหม่ทุกหมวด
DB00004 ภาพมี 2 targets; XML จริงมี 3รักษา Cytokine receptor common subunit gamma ตาม XML
DB00006 ภาพให้ transporter 1; XML มี 0ใช้ counts 1,1,0,0 ตามต้นทาง ไม่สร้าง transporter เพิ่ม
C1q มีหลาย polypeptides และหลาย actionsหนึ่ง block ต่อ entry เก็บทุก action/UniProt/gene ด้วย | และเก็บทุก subunit ใน JSON
ภาพมีแถวที่ความกว้างต่างกันassignment คงรูปแบบภาพ; table เสริมเติม empty cells และชื่อ header ไม่ซ้ำ

ตัวตรวจอิสระใช้สมมติฐานเดียวกันเรื่องหมวดและหลายค่า การผ่านทุก cell จึงยืนยันความตรงกับ XML ภายใต้วิธีที่ระบุ ไม่ใช่ใบรับรองคะแนนหรือความตรงเจตนาผู้สอน 100%
