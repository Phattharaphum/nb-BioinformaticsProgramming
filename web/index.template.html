03 / WRITE

เขียน CSV และแทนที่

v3/group3.py · export_csv

อ่าน spool กลับด้วย csv.reader เขียน UTF-8 BOM แล้ว os.replace ปลายทางเมื่อปิดไฟล์เสร็จ คืนจำนวนยาที่เขียน

ทำไมต้อง spool?

header ต้องครอบคลุมยาที่มี entries มากที่สุด ซึ่งทราบหลังอ่านครบ จึงพักข้อมูลลงดิสก์แล้วอ่านกลับแทนการเก็บทุกแถวใน RAM

หน่วยความจำยังขึ้นกับยาที่ใหญ่ที่สุด parser buffer และชุด IDs ที่ใช้ตรวจซ้ำ

ตรวจผลเมื่อไร?

V3 ไม่เรียก verifier หรือสร้าง JSON ระหว่างรัน การเขียนสำเร็จจึงเป็นคนละเรื่องกับการตรวจเทียบ XML

ระหว่างทดสอบใช้ tools/validate_v3.py ตรวจทุก cell ด้วยตัวอ่าน XML อิสระของ V2 และสร้างหลักฐานต้น–กลาง–ท้ายสำหรับเว็บไซต์

ตัวอย่าง XML จำลองสำหรับเข้าใจโครงสร้าง

ตัดเฉพาะฟิลด์ที่ใช้ในบทเรียน ไม่ใช่ไฟล์ XML ต้นทางฉบับเต็ม

<drugbank xmlns="http://www.drugbank.ca">
  <drug>
    <drugbank-id primary="true">DB00001</drugbank-id>
    <name>Lepirudin</name>
    <targets>
      <target>
        <name>Prothrombin</name>
        <organism>Humans</organism>
        <actions><action>inhibitor</action></actions>
        <polypeptide id="P00734" source="Swiss-Prot">
          <gene-name>F2</gene-name>
        </polypeptide>
      </target>
    </targets>
  </drug>
</drugbank>

08 / DOCUMENTED DECISIONS

!

Total-IonChannel ยังต้องยืนยันนิยาม

โจทย์ไม่ได้กำหนดเกณฑ์จำแนก ion channels ส่วน XML มี targets, enzymes, carriers และ transporters โปรแกรมนับ carriers ในคอลัมน์ที่สามตามสมมติฐานที่เปิดเผย แต่ carriers ไม่ใช่คำพ้องกับ ion channels

ตัวอย่าง DB00063 มี voltage-dependent N-type calcium channel อยู่ใน targets การนับ carriers จึงไม่ได้พิสูจน์จำนวน ion channels จริง และการค้นชื่อคำว่า channel อย่างเดียวไม่ใช่เกณฑ์ที่ครบถ้วน

specification_status = requires_ion_channel_definition
จุดที่พบสิ่งที่โปรแกรมเลือกทำ
หัวข้อคอลัมน์มีตัวสะกด IonChanel / IonChannelV3 คง Total-IonChannel เช่นเดียวกับ V2
Bivalirudin มีเลข 1 ทั้ง target และ enzymeเริ่ม protein_number ใหม่ทุกหมวด
DB00004 ภาพมี 2 targets; XML จริงมี 3รักษา Cytokine receptor common subunit gamma ตาม XML
DB00006 ภาพและ XML มี counts 1,1,0,0 ตรงกัน1 target, 1 enzyme และไม่มี carrier/transporter
