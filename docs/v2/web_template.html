03 / VERIFY

XML ↔ CSV ทุก cell

v2/verify_output.py

ใช้ stack และตัวอ่านอิสระ เทียบทุกแถว เก็บต้น/กลาง/ท้าย สถิติ complexes และ hashes ก่อนเผยแพร่ผล CSV/JSON

ทำไมต้อง spool?

header ต้องครอบคลุมยาที่มีรายการมากที่สุด ซึ่งทราบหลังอ่านครบ หากเก็บทุกยาใน RAM จะใช้หน่วยความจำมาก จึงพักค่าที่สกัดไว้ใน temporary JSONL แล้วอ่านกลับเพื่อเขียน CSV

ขนาดหน่วยความจำยังขึ้นกับยาที่ใหญ่ที่สุด parser buffer ชุด IDs สำหรับตรวจซ้ำ ตัวอย่าง 3 แถว และรายละเอียด complexes ในรายงาน

ผลเดิมจะถูกเขียนทับเมื่อไร?

หลัง parse, เขียน temporary CSV และตรวจเทียบผ่านแล้ว จึงเรียก os.replace เผยแพร่ CSV และ JSON ทีละไฟล์ หากสกัดหรือตรวจไม่ผ่านTemporaryDirectory จะลบ spool และไฟล์ชั่วคราวที่ยังเหลือเมื่อออกจาก context

การ replace แต่ละไฟล์เป็น atomic แต่ CSV และ JSON สองไฟล์ไม่ใช่ transaction เดียว หาก replace รายงานล้มเหลวหลัง replace CSV ต้องตรวจคู่ไฟล์ก่อนใช้งาน

ตัวอย่าง XML จำลองสำหรับเข้าใจโครงสร้าง

ตัดเฉพาะฟิลด์ที่ใช้ในบทเรียน ไม่ใช่ไฟล์ XML ต้นทางฉบับเต็ม

<drugbank xmlns="http://www.drugbank.ca">
  <drug>
    <drugbank-id primary="true">DB00001</drugbank-id>
    <name>Lepirudin</name>
    <targets>
      <target>
        <name>Prothrombin</name>
        <organism>Humans</organism>
        <actions><action>inhibitor</action></actions>
        <polypeptide id="P00734" source="Swiss-Prot">
          <gene-name>F2</gene-name>
        </polypeptide>
      </target>
    </targets>
  </drug>
</drugbank>

CLI options ของ V2 และการแก้ปัญหา
Optionค่าเริ่มต้นความหมาย

V2 ไม่มี --input-format, --layout และ --report ของ V1 หากเปลี่ยนชื่อ output ต้องระบุ --csv ชื่อเดียวกันเมื่อตรวจซ้ำ

  • หา input ไม่พบ: ตรวจ XML กับ current directory หรือระบุ --input; ไม่มีการ fallback ไป TXT
  • XML ผิดรูป/ขาดตอน หรือ IDs หาย/กำกวม/ซ้ำ: หยุดพร้อม ERROR และ exit 1

  • ปลายทางต้องเป็นไฟล์ใน directory ที่มีอยู่ และไม่ทับ input/report

การตรวจข้อมูลของ V2 ไม่ใช้ assert จึงยังทำงานเมื่อรัน Python -O สำเร็จ exit 0; ผิดพลาด exit 1

Total-IonChannel ยังต้องยืนยันนิยาม

โจทย์ไม่ได้กำหนดเกณฑ์จำแนก ion channels ส่วน XML มี targets, enzymes, carriers และ transporters โปรแกรมนับ carriers ในคอลัมน์ที่สามตามสมมติฐานที่เปิดเผย แต่ carriers ไม่ใช่คำพ้องกับ ion channels

ตัวอย่าง DB00063 มี voltage-dependent N-type calcium channel อยู่ใน targets การนับ carriers จึงไม่ได้พิสูจน์จำนวน ion channels จริง และการค้นชื่อคำว่า channel อย่างเดียวไม่ใช่เกณฑ์ที่ครบถ้วน
