3. วิธีจัดการข้อมูลและเหตุผล

  • นับ interaction entries ไม่ใช่จำนวน peptides: DNA อาจไม่มี peptide และ complex อาจมีหลาย subunits
  • เก็บทุก actions/UniProt/gene ตามลำดับและ Nan placeholders ไม่ทำให้คู่ค่าเลื่อนเมื่อข้อมูลบางตำแหน่งหาย
  • ต้องอ่านครบก่อนทราบ maximum blocks จึงใช้ spool บนดิสก์แทนเก็บทุกยาใน RAM
  • CSV เขียนด้วย csv.writer เพื่อรักษา comma/quote/newline และภาษาไทย
  • การสกัด/เขียนล้มเหลวก่อน replace ไม่ทับ CSV เดิม การเขียนสำเร็จไม่ได้เป็นผลตรวจอิสระ

V2 มีสองไฟล์ 272 บรรทัดและตรวจอัตโนมัติ V3 แยกงานตรวจออกจาก runtime แต่คงข้อมูล CSV เดิม 110 เป็นฉบับกระชับที่ทดสอบแล้ว ไม่ใช่จำนวนต่ำสุดที่พิสูจน์ว่าลดต่อไม่ได้
