3. หลักการสกัดและกรณีพิเศษ

  • ใช้ namespace wildcard และ direct children เลือก primary ID; fallback เฉพาะ DB ID เดียวที่ไม่กำกวม ตรวจ ID หาย/ผิด/ซ้ำ และไม่เอา nested drug ใน pathways มานับเพิ่ม
  • นับ entries ใน targets → enzymes → carriers → transporters รวม DNA ไม่มี polypeptide รักษาลำดับ XML ไม่ sort position และไม่ deduplicate ข้ามบทบาท
  • ชื่อ/organism ระดับ entry มาก่อน polypeptide; UniProt ใช้ attribute id ไม่ใช่ BE ID หลาย actions/peptides คั่นด้วย | พร้อม Nan placeholders เพื่อรักษาคู่ ID/gene
  • UTF-8 BOM กับ csv.writer รักษา comma, quote, newline และภาษาไทย; JSON เก็บทุก subunit ของ complexes

Python 3.10 ขึ้นไป ใช้ standard library; environment ที่ทดสอบคือ .venv Python 3.14.4 วางสอง .py กับ XML ในโฟลเดอร์เดียวกันก็รันได้ ไม่ต้องมี V1 หรือเว็บไซต์
